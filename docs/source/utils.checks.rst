Checks Module
==============

The Checks module provides validation and constraint checking functions for BIDS datasets,
entities, and data structures. These functions verify compliance with BIDS specifications
and data integrity.

Overview
--------

Validation functions include mainly checks for presence of different root level files, like
READMEs, Citation, and License files.
